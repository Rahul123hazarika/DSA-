### What is an Array?
An array is a data structure that stores multiple values in a single variable. Each value has an index. 
Usually, indexing starts from 0.
```
arr = [10, 20, 30, 40, 50]
```
Index positions:
```
Index:  0   1   2   3   4
Value: 10  20  30  40  50
```
```
arr[0] = 10
arr[1] = 20
arr[4] = 50
```
## Basic Array Operations
### 1. Access:
```java
   int arr[]={1,2,4,5,6};
   System.out.print(arr[2]);
``` 
output: 4
